# EMORA Clean V8

Railway uchun soddalashtirilgan, dependency-siz demo build.

## GitHub'ga yuklash
ZIP'ni oching va **ichidagi fayl/papkalarni** repo root'iga yuklang. `package.json`, `server.mjs`, `Dockerfile`, `railway.json` repo boshida turishi kerak.

## Railway
1. New Project → Deploy from GitHub repo.
2. Repo'ni tanlang.
3. Variables qo'shish shart emas.
4. Deploy tugagach Settings → Networking → Generate Domain.
5. Railway portni o'zi aniqlashi kerak. `PORT` ni qo'lda yaratmang.
